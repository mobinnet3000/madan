# پروژه مَدَن — سامانه مدیریت خطوط فرآوری معدن

یک **وب‌اپلیکیشن کامل (Full-Stack)** برای مدیریت کارخانه‌ها، خطوط تولید، دستگاه‌ها،
لاگ‌های عملکرد و تحلیل‌های روزانه در صنعت معدن. رابط کاربری به زبان **فارسی (RTL)**،
با دارک‌مود، نمودارهای تعاملی و انیمیشن است.

> هدف این مخزن: هر کسی با کمترین دانش فنی بتواند پروژه را **کلون، اجرا و ویرایش** کند.

## 🚀 راه‌اندازی سریع (ویندوز — با یک کلیک)

۱. مخزن را کلون کنید:

```powershell
git clone https://github.com/mobinnet3000/madan.git
cd madan
```

۲. دابل‌کلیک روی **`setup.bat`** کنید و منتظر بمانید. این فایل به‌طور خودکار انجام می‌دهد:
   - ساخت محیط مجازی پایتون (`venv`)
   - نصب تمام کتابخانه‌های پایتون
   - ساخت دیتابیس و اجرای Migrationها
   - بارگذاری **داده‌های نمونه (Demo Data)** شامل ۴ کارخانه، ۱۰ خط، ۳۷ دستگاه و کاربران
   - نصب کتابخانه‌های فرانت‌اند و ساخت (Build) آن

۳. وقتی پیام «Setup complete» دیدید، دابل‌کلیک روی **`start.bat`** کنید.
   دو پنجره باز می‌شود:
   - **Backend** روی http://localhost:8000
   - **Frontend** روی http://localhost:5173 (اگر اشغال باشد 5174، 5175، ...)

۴. مرورگر را باز کنید و بروید به آدرس فرانت‌اند. با یکی از کاربران زیر وارد شوید:

| نقش | نام کاربری | رمز عبور |
|-----|-----------|----------|
| مدیر کل (admin) | `admin` | `Madan@1404` |
| مدیر کارخانه | `manager1` | `Madan@1404` |
| اپراتور | `operator1` | `Madan@1404` |

> نکته: تمام رمزهای عبور کاربران نمونه یکسان و `Madan@1404` هستند.

## ⚙️ نصب دستی (برای لینوکس / مک / یا کنترل بیشتر)

### ۱. بک‌اند (Django + DRF)

```powershell
# محیط مجازی
python -m venv venv
venv\Scripts\activate        # ویندوز
# source venv/bin/activate   # لینوکس / مک

# نصب کتابخانه‌ها
pip install --upgrade pip
pip install -r requirements.txt

# دیتابیس
python manage.py migrate

# داده‌های نمونه (اختیاری ولی پیشنهادی)
python seed_demo.py

# اجرای سرور
python manage.py runserver 0.0.0.0:8000
```

بک‌اند حالا روی `http://127.0.0.1:8000` در دسترس است.
مستندات API در `http://127.0.0.1:8000/api/` قابل مشاهده است.

### ۲. فرانت‌اند (React + Vite + TypeScript)

```powershell
cd frontend
npm install
npm run dev          # حالت توسعه (Development)
# npm run build      # ساخت نسخه نهایی در پوشه dist/
```

فرانت‌اند به‌صورت خودکار درخواست‌های `/api` را به بک‌اند (پورت ۸۰۰۰) هدایت می‌کند،
پس حتماً بک‌اند باید روشن باشد.

## 🌐 اشتراک‌گذاری روی اینترنت (بدون سرور)

برای نمایش پروژه به کارفرما یا دوست از روی لپ‌تاپ خودتان، از **Cloudflare Tunnel**
استفاده کنید (نیازی به ثبت دامنه یا باز کردن پورت روتر ندارد):

۱. فایل `cloudflared.exe` را از https://github.com/cloudflare/cloudflared/releases دانلود کنید
   و در پوشه اصلی پروژه قرار دهید (یا در PATH باشد).

۲. در ترمینال اجرا کنید (پورت فرانت‌اند را تنظیم کنید):

```powershell
cloudflared tunnel --url http://localhost:5173
```

۳. لینکی شبیه `https://xxxx.trycloudflare.com` به شما می‌دهد؛ آن را به هر کسی بدهید.
   کانفیگ Vite روی `allowedHosts: true` تنظیم شده، پس با هر لینکی کار می‌کند.

> نکته: تونل تا زمانی که پنجره ترمینال باز است فعال است. بستن پنجره = قطع لینک.

## 🗂 ساختار پروژه

```
madan/
├─ accounts/        # کاربران، نقش‌ها، احراز هویت (Django)
├─ core/            # تنظیمات اصلی Django (settings, urls)
├─ machines/        # مدل‌ها، سریالایزرها و APIهای اصلی (کارخانه/خط/دستگاه/لاگ/تحلیل)
├─ media/           # تصاویر دستگاه‌ها (توسط seed ساخته می‌شود)
├─ static/          # فایل‌های استاتیک جمع‌آوری‌شده (gitignore شده)
├─ frontend/        # پروژه React + Vite
│  ├─ src/
│  │  ├─ api/       # توابع ارتباط با بک‌اند
│  │  ├─ components/# کامپوننت‌های UI و لایه‌بندی
│  │  ├─ pages/     # صفحات (Dashboard, Lines, Logs, Analysis, Reports, ...)
│  │  ├─ store/     # مدیریت وضعیت (Auth, Factory)
│  │  └─ types.ts   # تایپ‌های TypeScript
│  ├─ vite.config.ts# پروکسی /api و /media به بک‌اند
│  └─ package.json
├─ seed_demo.py     # اسکریپت تولید داده‌های نمونه
├─ requirements.txt # کتابخانه‌های پایتون
├─ setup.bat        # نصب خودکار (ویندوز)
├─ start.bat        # اجرای همزمان بک‌اند و فرانت‌اند
├─ start.sh         # اجرای همزمان (لینوکس/مک)
└─ README.md
```

## ✏️ ویرایش و توسعه

- **تغییر ظاهر / رنگ‌ها:** فایل `frontend/tailwind.config.js` و `frontend/src/index.css`
- **تغییر صفحات:** پوشه `frontend/src/pages/`
- **تغییر APIها / مدل‌ها:** پوشه‌های `machines/` و `accounts/` در بک‌اند
- **افزودن فیلد به مدل:** مدل را در `machines/models.py` تغییر دهید، سپس:
  ```powershell
  python manage.py makemigrations
  python manage.py migrate
  ```
- **تغییر داده‌های نمونه:** فایل `seed_demo.py` را ویرایش و دوباره اجرا کنید
  (اول `del db.sqlite3` برای شروع تازه).

فرانت‌اند به‌صورت خودکار با ذخیره فایل (Hot Reload) به‌روز می‌شود.

## 🔑 نکات مهم

- در حالت توسعه `DEBUG = True` و `ALLOWED_HOSTS = ['*']` است؛ **برای تولید واقعی**
  حتماً تنظیمات امنیتی را تغییر دهید.
- دیتابیص پیش‌فرض `db.sqlite3` است و در git قرار ندارد؛ با اجرای `seed_demo.py` ساخته می‌شود.
- رمزهای عبور نمونه صرفاً برای دمو هستند؛ قبل از انتشار واقعی تغییر دهید.

## ❓ خطایابی

| مشکل | راه حل |
|------|--------|
| `python` شناخته نشد | پایتون را نصب و به PATH اضافه کنید |
| خطای پورت ۸۰۰۰ درگیر است | برنامه دیگری را ببندید یا پورت را در `start.bat` تغییر دهید |
| فرانت‌اند `Blocked host` می‌دهد | نگران نباشید؛ `allowedHosts: true` تنظیم شده است |
| API کار نمی‌کند | مطمئن شوید بک‌اند روی ۸۰۰۰ روشن است و `npm run dev` اجرا شده |
| نمودارها خالی است | `seed_demo.py` را اجرا کرده‌اید؟ |
