# سیستم دیزاین سامانه مدیریت معدن و خطوط فرآوری (Industrial Mining Design System)

> این سند راهنمای جامع طراحی هویت بصری، مقیاس رنگ‌های سازمانی، تایپوگرافی، سایه‌ها، فواصل و کامپوننت‌های رابط کاربری سامانه است. این طراحی به نحوی تدوین شده که استانداردهای مدرن محصولات رده‌بالا (Enterprise Grade / Crafted by Senior Product Designers) را برآورده سازد.

## ۲. تایپوگرافی و مقیاس متن (Typography System)

- **فونت اصلی فارسی:** `Vazirmatn` (وزن‌های ۳۰۰، ۴۰۰، ۵۰۰، ۶۰۰، ۷۰۰، ۸۰۰) با اصلاح کرنینگ و خوانایی صنعتی.
- **فونت اعداد و کدها:** `Fira Code` و فونت‌های Monospace با فعال‌سازی ویژگی `tabular-nums` در نمایش داده‌های تنسی و زمانی.

```
Display:      32px / 40px (Bold 800)  - سرتیترهای داشبورد و عناوین اصلی
Heading 1:    24px / 32px (Bold 700)  - تیتر صفحات و مودال‌های تمام‌صفحه
Heading 2:    18px / 26px (Bold 600)  - تیتر کارت‌ها و بخش‌ها
Body Regular: 14px / 22px (Regular 400) - متن پیش‌فرض فرم‌ها و سلول‌های جدول
Body Small:   12px / 18px (Medium 500)  - برچسب‌های فیلدها و اطلاعات متادیتا
Caption:      11px / 16px (Regular 400) - راهنماهای زیرین و واحدها
```

## ۳. طراحی کامپوننت‌ها (Component Archetypes)

### دکمه ورود و اقدام اصلی (Primary Button):
- پس‌زمینه: Solid `#efa73f` با گرادینت بسیار ظریف `linear-gradient(180deg, #f5b452 0%, #efa73f 100%)`.
- متن: Bold با رنگ `#0f1821` (مشکی-نوک‌مدادی عمیق سازمانی) جهت کسب بالاترین کنتراست چشمی (WCAG AAA).
- انحنای لبه (Border Radius): `14px` (`rounded-xl` ارگونومیک).
- سایه (Box Shadow): سایه نرم و طبیعی `0 4px 14px rgba(239, 167, 63, 0.3)`.

### دکمه ثانویه / ارتباط با ما (Secondary Outline Button):
- پس‌زمینه: شفاف / سفید روی پس‌زمینه گرم.
- حاشیه (Border): حاشیه ضخامت `1.5px` با رنگ یاقوتی `#c92127`.
- متن: رنگ یاقوتی `#c92127` به همراه آیکون فلش با انیمیشن ترنزیشن هاور.
- هاور: پس‌زمینه محو قرمز روشن (`#c9212708`) با حرکت نرم آیکون فلش.

## ۴. مقیاس فواصل (8-Point Grid Spacing)
همه حاشیه‌ها، پدینگ‌ها و گپ‌ها مضربی از ۴ یا ۸ پیکسل هستند:
- `4px` (space-1): فاصله بین آیکون و متن داخل بج‌ها.
- `8px` (space-2): فاصله پیش‌فرض داخلی فیلدهای ورودی و چیپ‌ها.
- `12px` (space-3): گپ بین دکمه‌های هم‌سطح.
- `16px` (space-4): پدینگ استاندارد کارت‌ها و سلول‌های جدول.
- `24px` (space-6): فاصله بین سکشن‌های اصلی و گروه‌بندی فرم‌ها.
- `32px` (space-8): پدینگ صفحه و فاصله‌های کلی داشبورد.
